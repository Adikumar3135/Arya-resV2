menu.html   - Visual menu with featured food photography and filters

order.html  - Order flow + generated order number + WhatsApp confirmation

WhatsApp number is currently set to +919000000000 in script.js/links as a placeholder.
Replace it with the restaurant's real WhatsApp number before production.

Booking:
The table booking form opens WhatsApp with name, guests, date and time.

Ordering:
Order number is generated in browser and the order details are sent to WhatsApp.

The forms are intentionally frontend-ready. For a real production system, connect them to PHP/MySQL or another backend for persistent bookings/orders.
Images/fonts/GSAP/Lenis are loaded from CDNs.
